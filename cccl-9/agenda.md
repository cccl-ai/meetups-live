## How it works

LON9 is a set of **katas** — short, focused exercises, each one under five minutes. You don't watch someone else type; you do every one yourself, on your own laptop. After each kata we check in with everyone in the room before moving on. **100% completion is the goal, not just attendance — everyone finishes together.**

## What you'll learn

- How to read, edit, and create files using Claude Code
- How to run git commands and commit your work
- How to give Claude Code permanent project instructions
- How to use plan mode to review before anything changes
- How to search your codebase and explain changes

Each kata builds on the last.
