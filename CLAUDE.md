# meetups-live

Jekyll site served at `https://cccl-ai.github.io/meetups-live/`.

## Run locally

```bash
cd ~/gitper/meetups-live && /opt/homebrew/opt/ruby/bin/ruby /Users/vikram/.gem/ruby/4.0.0/gems/jekyll-4.4.1/exe/jekyll serve --port 4000 --detach
```

URL: http://localhost:4000/meetups-live/

To stop: `pkill -f jekyll`

> Note: do NOT use system Ruby (`/usr/bin/ruby`) — use Homebrew Ruby at `/opt/homebrew/opt/ruby/bin/ruby`.
